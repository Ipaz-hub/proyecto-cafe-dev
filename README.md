# Café Dev - Proyecto para el taller de Git y GitHub

Este proyecto está preparado para practicar tus habilidades con Git y GitHub.

## Importante

- No necesitas saber HTML, CSS o JavaScript más allá de lo básico.
- Cada cambio está indicado dentro de `index.html`.
- Cada integrante debe realizar exactamente **3 commits** en su rama.
- El **tag debe apuntar al segundo commit**, no al último.
- Todos modifican la misma frase durante el segundo commit para provocar un conflicto controlado.

## Cambios por commit

1. Agregar tu nombre al equipo.
2. Cambiar el mensaje principal (zona de conflicto) y crear el tag.
3. Cambiar el texto del botón.
